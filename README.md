这版把网页和 DeepSeek 代理放在同一个 Cloudflare Worker 上，批处理页面请求本站的 `/api/evaluate-intelligences`，不再直接跨域调用 DeepSeek。DeepSeek API Key 只作为 Cloudflare Secret 保存在服务端。

## 部署

需要 Cloudflare 账户、Node.js 和 npm。在本项目目录打开终端：

```bash
npx wrangler@latest login
npm run deploy
```

首次部署后，需要配置密钥才能使用 DeepSeek。然后分别运行下列命令，按提示输入真实值：

```bash
npx wrangler@latest secret put DEEPSEEK_API_KEY
npx wrangler@latest secret put APP_PASSWORD
```

`APP_PASSWORD` 是老师自己设置的**个人访问口令**，不是 DeepSeek API Key。请使用长度至少 20 位的随机口令，不要与其他网站共用。密钥不要写进 `wrangler.jsonc`、网页或聊天消息中。设置好后刷新部署网址，在页面的“DeepSeek 连接与个人口令”中输入个人口令，再生成评价。

若网页提示“DeepSeek 尚未配置”，确认两个 Secret 都已设置，并刷新页面。若显示“个人访问口令不正确”，检查输入的是否为 `APP_PASSWORD`，而非 DeepSeek API Key。

## 本地测试

把 `.dev.vars.example` 复制为 `.dev.vars`，在副本中填入测试用密钥和个人访问口令，然后运行：

```bash
npm run dev
```

`.dev.vars` 已被 Git 忽略，不要把真实密钥放入压缩包或提交到代码仓库。只做不联网的自动测试可运行 `npm test`。

## Excel 批量填写

首页 `/` 直接打开 Excel 批量填写；旧批处理链接 `/excel.html` 会跳转到首页。单人预览仍可在批处理内使用。

Excel 批量页面的处理流程：

1. 上传本周课堂评价文件。表头保持为“序号 / 孩子姓名 / 本周课堂评价”，学生行数可以增减，空行会自动忽略。有姓名但评价为空或为 / 时，所选智能记 0 分并跳过模型生成。
2. 上传多元智能成长记录模板，可以使用没有学生姓名的空模板。系统会扫描所有包含“孩子姓名”及八大智能列的工作表，已有学生按中文姓名匹配，新学生按工作表顺序自动写入空白姓名行；模板中的英文名不会影响匹配。
3. 按需填写周次、记录日期、带班老师和班级；这些信息会写入所有成长记录工作表的顶部，留空则保留模板原内容。
4. 系统会读取模板“填写说明”工作表中的智能定义、评分标准和填写提示，并将其作为参考标准随课堂评价发送给 DeepSeek。模板内容只作为参考数据，不会覆盖系统的事实约束和 JSON 输出规则。
5. 选择本次要生成的一个或多个智能维度，填写个人访问口令并批量生成。每个所选维度都会生成 1—5 分和观察记录；返回内容采用弱校验，数字字符串等级自动转换，无效等级默认 3 分，缺失维度、等级缺失或为 /、观察记录为空或为 / 时记 0 分并留空记录，直接跳过补写，不因说明性措辞或记录长度而整组失败。直接证据有限时使用 3 分，围绕原文已有课堂状态自然改写，避免虚构具体表现。
   全选八个维度时自动分为四组依次生成，每组最多两个维度，显示学生与维度进度。失败组等待后自动重试一次；成功组立即写入，失败组保留原单元格内容，最终显示失败维度。浏览器请求超过 75 秒会结束等待。
6. 下载填写结果。系统只改写所选智能的“表现等级”和“亮点/观察记录”，未选择的智能和其他列保持原样。可以在同一次页面会话中分几次选择不同智能继续填写。

Excel 文件在浏览器本地解析与导出；调用 DeepSeek 时，仅学生姓名与对应的本周课堂评价会经 Worker 发往模型服务。未匹配姓名会在页面中列出，不会自动写入不确定的班级或行。

## 隐私与安全

- 不使用 DeepSeek 时，评价由浏览器内的固定模板生成，课堂文字不会发往模型。
- 使用 DeepSeek 时，课堂文字经 Cloudflare Worker 发送给 DeepSeek；服务端不建立学生数据库，也不保存评价历史。Excel 批处理会在当前浏览器 IndexedDB 自动保存一个本机草稿（原模板、学生评价、生成结果、勾选和设置），不保存访问口令；可以恢复上次任务或清除本机草稿。
- 网页本身可以被访问到，但 `/api/evaluate` 必须提供正确的个人访问口令。若希望**整个网页**也仅本人可见，可另为部署网址配置 Cloudflare Access。
- 不要再双击旧版 `teacher_evaluation.html` 使用 AI 功能；请通过部署后的 Cloudflare 网址打开新版。

代码结构：`dist/index.html` 是页面，`src/worker.js` 是 API 代理，`wrangler.jsonc` 是 Cloudflare 配置。

## 批处理续做与预览

- 选齐两个文件后自动匹配，默认勾选所有匹配学生和八项智能。
- 可以搜索姓名、筛选未完成或有失败记录的学生，按勾选名单生成；筛选本身不会改变勾选。
- “先生成一人预览”只处理第一位勾选且有未完成项的学生。预览结果会写入正式文件，批量生成跳过成功项。
- 支持暂停后继续；成功项按当前字数设置记录进度，改变字数后允许重新生成。
- 文件解析后和每组生成后自动保存本机草稿；刷新后点击“恢复上次任务”，无需重新上传，访问口令需要重新填写。
- “清除本机草稿”删除浏览器中的草稿，当前页面任务继续保留；本次不再自动保存，新上传匹配文件后重新启用。
- 浏览器存储不可用或空间不足时会提示保存失败，请及时下载。草稿只适用于当前浏览器和当前站点，不会跨设备同步。
