# 常见问题

[返回指南首页](Home.md)

## 生成按钮为什么不能点击？

先匹配两个文件，至少勾选一名可处理学生，至少选择一个智能。如果显示“所选项目已完成”，说明当前字数下没有待处理项。

## 为什么只搜索一个学生，还会处理别人？

搜索和筛选不改变勾选。先取消全部学生勾选，再搜索并勾选指定学生。看“已选 X / Y 人”确认范围。

## 口令不正确、服务未连接怎么办？

检查个人访问口令，恢复草稿后需重新输入。不要用 DeepSeek API Key 代替个人口令。余额不足或服务配置问题请联系管理员。

## 一个智能失败，会丢掉其他结果吗？

不会。每组最多两个维度；成功项立即保存，失败组重试一次。可继续补未完成项，或先下载已完成部分。

## 为什么出现 0 分？

缺失或 `/` 按跳过规则处理。它表示无填写观察，不用于给孩子能力定级。详见[填写规则](Export-and-Rules.md)。

## 草稿为什么找不到？

必须使用同一浏览器、同一站点。无痕模式、清理站点数据、更换设备可能导致草稿丢失。正式文件应下载留存。

## 可以直接改生成的文字吗？

单人页面可以直接编辑与复制；批处理页面可展开查看，修改请在下载后的 Excel 中完成。

## 如何重新生成已完成内容？

同一字数设置下会跳过成功项；改变字数后可再次预览。当前版本没有独立的“强制重生成”按钮。重新上传匹配文件会建立新任务，请先下载保留现有结果。

## 下载会清掉草稿吗？

不会。需要删除本机草稿时，点击“清除本机草稿”。
