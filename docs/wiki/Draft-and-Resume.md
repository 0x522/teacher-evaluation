# 本机草稿恢复与暂停续做

## 暂停后继续

点击“暂停”后，会先完成当前组再停下。点击继续时只补未完成的项目，成功内容保留。

## 刷新后恢复

1. 使用同一个浏览器打开同一个软件地址。
2. 点击顶部“恢复上次任务”。
3. 核对名单、设置与进度，重新输入个人访问口令。
4. 继续生成或直接下载已完成部分，无需重新上传两个文件。

## 草稿保存什么

| 保存到当前浏览器 | 不保存 |
| --- | --- |
| 原模板、学生姓名、课堂评价 | 个人访问口令 |
| 生成结果、完成项、学生勾选 | 跨设备和跨浏览器同步副本 |
| 字数、周次、日期、老师、班级 | 服务端学生历史数据库 |

匹配后及每组成功后自动保存。关闭前留意“草稿已保存”；如果浏览器存储不可用或空间不足，请先下载当前结果。

## 清除草稿

“清除本机草稿”删除浏览器中的草稿，当前页面任务继续保留；本次不再自动保存。新上传并匹配文件后恢复自动保存。共用电脑使用完可以清除草稿。

无痕模式、清除站点数据、更换浏览器或设备，都可能使草稿无法恢复。正式结果请下载留存。
