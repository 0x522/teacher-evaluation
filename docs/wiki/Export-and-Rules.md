## 下载前核对

- **姓名与位置**：匹配正确，新增学生进入正确工作表和行。
- **分数与事实**：文字和评分符合真实观察。
- **顶部信息**：周次、日期、老师、班级正确。

点击“下载填写结果”，得到“原模板名-已填写.xlsx”。可随时下载已完成部分，再在 Excel 中修改文字、调整行高和自动换行。

## 填写规则

| 情况 | 处理方式 |
| --- | --- |
| 缺失维度、缺失等级或等级为单独的 `/` | 该项记 0 分，记录留空，跳过补写。 |
| 观察记录为空或为单独的 `/` | 该项记 0 分，记录留空。 |
| 整条学生课堂评价为空或为单独的 `/` | 所选智能全部记 0 分，不调用模型。 |
| 已有有效结果 | 写入所选智能，未选智能列保持原样。 |
| 请求仍失败 | 保留原单元格；可继续补做。 |

> **0 分是跳过标记，不是孩子能力低的判断。**

## 覆盖提示

当前版本会改写所选智能对应的等级和记录。0 分跳过也会写入 0 并清空对应记录。使用带历史内容的模板前，请保留原文件副本。

## 数据流向

Excel 在浏览器本地解析。调用 DeepSeek 时，学生姓名、课堂评价、所选维度和模板填写说明经 Cloudflare Worker 发往模型服务。API Key 只存服务端；本机草稿不保存口令。请避免输入不必要的敏感信息。
