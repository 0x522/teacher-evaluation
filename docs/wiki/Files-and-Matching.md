# Excel 文件准备与姓名匹配

[返回指南首页](Home.md)

支持 `.xlsx`；每个文件最大 15MB。不要上传 CSV 或旧版 `.xls`。

![课堂评价文件和成长记录模板两个上传入口](assets/upload-files.png)

## 1. 准备本周课堂评价

建议表头如下，每行一名学生：

| 序号 | 孩子姓名 | 本周课堂评价 |
| --- | --- | --- |
| 1 | 小禾 | 跟随节奏拍手，主动邀请同伴参与。 |
| 2 | 小林 | / |

全空行自动忽略。有姓名但评价为空或为单独的 `/`，所选智能会记 0 分，不调用模型。不要把解释文字与 `/` 一起填入单元格。

## 2. 准备成长记录模板

- 保留“孩子姓名”、八大智能及对应的“表现等级”“亮点/观察记录”列。
- 可以使用空模板；系统按工作表顺序向空白姓名行写入新学生。
- 已有学生按中文姓名匹配，模板中的英文名一般不影响匹配。
- 若提示模板空白行不足，先扩充模板的空白学生行，再重新匹配。
- 若模板含“填写说明”，系统会提取智能定义、评分标准和填写提示作为模型参考。

## 3. 选择文件，自动匹配

选齐两个文件后自动解析。核对下方学生名单、未匹配提示和可处理人数，再开始生成。

周次、记录日期、带班老师、班级均可留空；填写后会写入所有成长记录工作表顶部，留空保留原内容。
